Covenant CachyOS Builder

Builder de ISO customizada do CachyOS (Desktop/Plasma), com branding próprio e otimizações de performance. A maior parte das otimizações usa detecção automática de hardware — funcionam em qualquer máquina.

Como fazer o build

Dois modos de build. O modo RAM é mais rápido, mas exige bastante memória livre.

Build normal
bash build-iso.sh
Build em RAM
bash build-iso.sh -r
ISO gerada
cachyos-live-iso/out/desktop/Covenant-CachyOS-*.iso
Gravar no pendrive
sudo dd if='<iso>' of=/dev/sdX bs=4M status=progress oflag=sync
Nota: Esta versão é uma build incremental e isolada — começou 100% pura e cada customização foi reintroduzida e testada separadamente, para facilitar o diagnóstico (especialmente problemas de GPU/Wayland).
Pipeline

O que o build faz

Do zero até a ISO final, com retry automático e correções defensivas.

1

Dependências e mirrors

Instala git, archiso e cachyos-rate-mirrors. Seleciona os mirrors mais rápidos e atualiza os bancos de pacotes.

2

Clone e patch do Calamares

Clona o cachyos-live-iso oficial e patcha o calamares-online.sh para não reinstalar o Calamares (causa raiz do instalador não abrir + perda de branding).

3

Pacotes e branding

Substitui a lista de pacotes, aplica branding Covenant (10 slides PNG), copia wallpapers e limpa o instalador para oferecer só Plasma e Hyprland.

4

Hooks de segurança

Cria hook do pacman que reaplica branding se o pacote for reinstalado. Adiciona IgnorePkg para cachyos-calamares-next. Injeta covenant-target-setup sem sobrescrever o upstream.

5

MachCtrl + auto-correção

Builda machctrl-bin a partir do AUR e embute na ISO. Verifica com ldd se o Calamares carrega todas as libs; se não, corrige boost-libs automaticamente via Arch Linux Archive.

6

ISO final

Gera arquivos de otimização pós-instalação, configura makepkg.conf, nomeia a ISO como Covenant-CachyOS-<data>-<sufixo> e builda com retry automático (3×).

Performance

Otimizações pós-instalação

Rodam apenas no sistema instalado, uma única vez no primeiro boot (covenant-first-boot.service). Nunca na sessão live.

  • Governor performance em todos os núcleos (também via covenant-cpu-governor.service)
  • GPU forçada para power_dpm_force_performance_level=high
  • Kernel cmdline: mitigations=off, processor.max_cstate=1, intel_idle.max_cstate=1, transparent_hugepage=always, nowatchdog, amdgpu.ppfeaturemask=0xffffffff, amd_pstate=active
  • TCP BBR + fq_pie como qdisc padrão
  • Buffers aumentados: rmem_max/wmem_max em 128 MB, optmem_max=65536, somaxconn=8192, netdev_max_backlog=16384
  • tcp_timestamps=0, tcp_slow_start_after_idle=0, tcp_fin_timeout=15
  • tcp_fastopen=3 — Fast Open em cliente e servidor
  • tcp_mtu_probing=1 — MTU Path Discovery automático
  • Módulo tcp_bbr carregado no boot
  • swappiness=10, vfs_cache_pressure=50
  • page-cluster=0 — sem readahead de swap
  • compaction_proactiveness=0 — sem compactação proativa
  • Huge Pages: 512 páginas de 2 MB
  • ZRAM desativado (mascarado via systemd)
  • Dirty pages: dirty_ratio=20, dirty_background_ratio=10
  • NVMe: scheduler none, nr_requests=1024, read_ahead_kb=256
  • SSD SATA: mq-deadline, rq_affinity=2, add_random=0
  • HDD: bfq, read_ahead_kb=2048 + hdparm -B 255 / -S 0
  • Regras udev com prefixo 99- (sobrescrevem defaults da CachyOS)
  • fstrim.timer habilitado
  • IRQs de NVMe e AMD GPU direcionadas para a metade dos cores lógicos disponíveis
  • Serviço covenant-irq-affinity.service
  • F2FS: noatime, nodiscard, compress_algorithm=lz4, lazytime
  • XFS: noatime, nodiscard, logbsize=256k, allocsize=64m
  • Backup automático do /etc/fstab antes de qualquer alteração
  • sched_autogroup_enable=0 — melhor throughput em workloads pesados
  • nmi_watchdog=0 — dupla garantia com nowatchdog no GRUB
  • perf_event_paranoid=-1 + kptr_restrict=0 — profiling sem root
  • unprivileged_userns_clone=1 — Flatpak, containers rootless e Chromium sandbox
  • Journald: persistente, comprimido, 256 MB / 1 semana. Coredumps desativados
  • makepkg: MAKEFLAGS="-j$(nproc)", CFLAGS="-march=native", RUSTFLAGS="-C target-cpu=native"
  • Polkit: montagem/desmontagem sem senha para grupo wheel
  • Limites: nofile e memlock elevados; inotify 524288 watches
  • Verificação: covenant-check.sh mostra o status de todas as otimizações

Instalador customizado

Modo instalação online, com branding Covenant e seleção enxuta de desktops.

🎨

Branding Covenant

10 slides PNG próprios durante a instalação, aplicados via staging neutro + reescrita do show.qml.

🖥️

Plasma + Hyprland

A tela de seleção oferece apenas “Sem Ambiente”, “Plasma Desktop” e “Hyprland”. Os demais desktops saem.

⚙️

Otimizações no target

covenant-target-setup injetado no shellprocess-before-online.conf, preservando o upstream do CachyOS.

Por que o Calamares não abria

O botão Launch Installer chamava calamares-online.sh, que fazia pacman -Sy cachyos-calamares-next antes de abrir o GUI. Em distro rolling isso quebra de dois jeitos:

Instalador não abre

O pacote novo vem compilado contra boost/qt/python que não existem no squashfs congelado da ISO.

Personalizações somem

O pacman restaura show.qml, netinstall.yaml, packagechooser e shellprocess originais.

Defesa em camadas: patch no calamares-online.sh (não reinstala), IgnorePkg no pacman.conf do live, e hook de reaplicação de branding fora de /etc/calamares/. Além disso, auto-correção de mismatch do boost-libs via Arch Linux Archive — se o ldd detectar lib faltando, baixa e instala a versão exata.
Pré-instalados

Ferramentas embutidas

Instaladas automaticamente no primeiro boot do sistema instalado.

📊

MachCtrl 3.0

Monitor e otimizador de hardware nativo para CachyOS. Buildado a partir do AUR durante o build da ISO e embutido nela. Instalado via pacman -U no primeiro boot, sem internet ou AUR helper.

📦

Pamac

Gerenciador gráfico de pacotes com suporte a AUR, do repositório oficial do CachyOS. Instalado no primeiro boot junto com o MachCtrl, após confirmar resolução DNS.
